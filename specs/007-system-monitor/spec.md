# Feature Specification: 系统监控模块前端交付

**Feature Branch**: `007-system-monitor`

**Created**: 2026-11-11

**Status**: Draft

**Input**: User description: "系统监控模块前端交付（在线用户 / Admin 监控 / 缓存监控 / 任务调度中心）。依据已签字 specs/SPEC-007-system-monitor.md v1.0：4 个视图；在线用户列表/精确筛选/本地分页/单条强退/前端批量强退；缓存监控仅基本信息+图表（后端无键浏览与清理接口）；Admin 监控与任务调度中心沿用 iframe 内嵌官方控制台；不修改 platform/、不新增依赖、不新增权限码。特性目录使用 specs/007-system-monitor，分支 007-system-monitor。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 在线用户查看与强制下线 (Priority: P1)

运维管理员打开在线用户页，按登录地址与用户名称查询当前在线会话，核对会话编号、登录名称、客户端、设备类型、所属部门、主机、登录地点、操作系统、浏览器与登录时间。发现异常会话时，对单条会话执行强退；需要批量处置时，勾选多条后执行批量强退。操作完成后列表立即刷新，并与后端数据一致。

**Why this priority**: 在线会话处置是安全事件响应与并发会话治理的直接手段；该页面不可用会延误异常账号的处置。它是本模块唯一的写操作页面，风险最高，必须最先交付。

**Independent Test**: 仅实现本故事即可独立验收：创建 2 个有效会话，打开页面确认列表与筛选正确；对其中 1 条执行单条强退，确认列表减少 1 条；勾选剩余 2 条执行批量强退，确认提示成功 2 条、失败 0 条，列表同步减少。

**Acceptance Scenarios**:

1. **Given** 用户 `spec007_online` 已建立 2 个有效会话且管理员已登录，**When** 打开在线用户页并不填筛选条件，**Then** 列表出现 2 条该用户的会话，总数等于返回行数，10 个字段列各出现 1 次，页面无未捕获异常。
2. **Given** 在线列表已加载，**When** 同时填写登录地址与用户名称并查询，**Then** 结果只包含同时满足两个条件的会话；只满足一个条件的会话不得出现。
3. **Given** 用户 `spec007_online` 有 1 个会话显示在列表中，**When** 点击该行强退并在确认弹窗点确定，**Then** 该会话从列表消失，总数减少 1，提示「强退成功」，页面无未捕获异常。
4. **Given** 勾选了 2 个有效会话，**When** 执行批量强退并确认，**Then** 两条会话均从列表消失，总数减少 2，提示包含「成功 2 条，失败 0 条」。
5. **Given** 批量强退中 1 条请求失败，**When** 执行批量强退，**Then** 其余条目继续执行，提示包含成功与失败数量以及后端失败原因，失败条目仍保留在列表。

### User Story 2 - 缓存运行状态巡检 (Priority: P1)

运维管理员打开缓存监控页，查看 Redis 版本、运行模式、端口、客户端数、运行天数、使用内存、使用 CPU、内存配置、AOF 与 RDB 状态、Key 数量与网络入口/出口，并通过命令统计饼图与内存仪表盘快速判断缓存健康状况。

**Why this priority**: 缓存是系统运行的关键依赖；该页面是 Redis 巡检与容量判断的唯一入口。页面只读，风险低于在线用户页，但业务价值同样属于 P1。

**Independent Test**: 仅实现本故事即可独立验收：在 Redis 可用时打开页面，确认 12 个基本信息字段、Key 数量、命令统计图表与内存图表均展示；在缓存接口失败时确认页面展示后端原因且不出现未捕获异常。

**Acceptance Scenarios**:

1. **Given** 缓存接口返回成功，**When** 打开缓存监控页，**Then** 12 个基本信息标签各出现 1 次，Key 数量显示为后端返回值，命令统计与内存图表各渲染 1 个画布。
2. **Given** 命令统计为空，**When** 打开页面，**Then** 命令统计区域显示「暂无数据」，内存图表仍正常渲染。
3. **Given** 缓存接口返回失败原因，**When** 打开页面，**Then** 页面展示后端原因原文，基本信息表与图表均不渲染，页面无未捕获异常。

### User Story 3 - 统一进入服务监控控制台 (Priority: P2)

运维管理员从系统菜单进入 Admin 监控页，页面内嵌官方服务监控控制台；控制台地址由部署环境提供。地址未配置时页面给出明确提示；控制台不可达时保留内嵌区域并提供在新窗口打开的入口。

**Why this priority**: 该页面是外部控制台的统一入口，不承载本系统自建指标；缺失会影响入口可达性，但不阻断在线用户与缓存巡检。

**Independent Test**: 配置控制台地址后打开页面，确认内嵌区域地址正确、外链地址一致；清空配置后确认页面提示未配置且不渲染内嵌区域。

**Acceptance Scenarios**:

1. **Given** 部署环境已配置 Admin 控制台地址，**When** 打开 Admin 监控页，**Then** 页面渲染 1 个内嵌区域，其地址与外链地址均等于配置值，内嵌区域高度不小于 400。
2. **Given** Admin 控制台地址为空，**When** 打开页面，**Then** 不渲染内嵌区域，显示「未配置监控地址」，外链不可点击。
3. **Given** Admin 控制台地址不可达，**When** 打开页面，**Then** 内嵌区域仍存在，外链可点击且地址等于配置值，页面不出现自造错误弹窗。

---

### User Story 4 - 统一进入任务调度控制台 (Priority: P2)

运维管理员从系统菜单进入任务调度中心页，页面内嵌官方 SnailJob 控制台；控制台地址由部署环境提供，地址未配置时给出明确提示。

**Why this priority**: 与 Admin 监控页同属外部控制台入口，独立交付；不涉及本系统数据读写。

**Independent Test**: 配置 SnailJob 地址后打开页面，确认内嵌区域地址与外链地址均等于配置值；清空配置后确认提示未配置且不渲染内嵌区域。

**Acceptance Scenarios**:

1. **Given** 部署环境已配置 SnailJob 控制台地址，**When** 打开任务调度中心页，**Then** 页面渲染 1 个内嵌区域，其地址与外链地址均等于配置值，内嵌区域高度不小于 400。
2. **Given** SnailJob 地址为空，**When** 打开页面，**Then** 不渲染内嵌区域，显示「未配置监控地址」，外链不可点击。

### Edge Cases

- 在线列表为空或筛选无匹配时，显示「暂无数据」，不弹错误提示。
- 登录地址与用户名称同时填写时按 AND 语义匹配；只匹配任一条件的结果不得出现。
- 筛选值包含特殊字符或类似注入的文本时，按精确等值处理，不返回 500。
- 有效会话超过每页 10 条时，第一页显示 10 条，其余进入后续页；翻页不重复请求列表。
- 会话在强退前已过期时，后端仍返回成功；前端按幂等成功处理并刷新列表。
- 批量强退中部分请求失败或超时时，继续执行其余请求，并按成功/失败数量汇总提示。
- 未勾选任何会话时，批量强退按钮不可用；确认弹窗取消时不发起请求。
- 连续快速确认批量强退时，不得重复发起请求。
- 缓存接口失败、基本信息缺键或命令统计为空时，分别展示后端原因、「—」与「暂无数据」。
- 外部控制台地址未配置或不可达时，按未配置提示与保留内嵌区域并给出外链两种行为处理。
- 不具备权限的用户直接访问受限页面时，页面不存在，且不发起对应数据请求。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在动态菜单中提供系统监控的 4 个视图：在线用户、Admin 监控、缓存监控、任务调度中心；这 4 个路径 MUST NOT 出现「即将推出」占位页。
- **FR-002**: 在线用户列表 MUST 展示会话编号、登录名称、客户端、设备类型、所属部门、主机、登录地点、操作系统、浏览器、登录时间 10 列；行顺序 MUST 与后端返回顺序一致；总数 MUST 等于返回行数。
- **FR-003**: 在线用户列表 MUST 支持按登录地址与用户名称筛选；两个条件同时填写时 MUST 按 AND 语义匹配；空串 MUST 表示不过滤；匹配 MUST 为精确等值，不支持模糊与通配符；MUST 提供重置筛选。
- **FR-004**: 在线用户列表 MUST 采用本地分页，默认每页 10 条；有效会话超过 10 条时 MUST 可翻页查看其余条目；翻页 MUST NOT 重新请求后端列表。
- **FR-005**: 在线用户 MUST 支持单条强退；执行前 MUST 二次确认；成功后 MUST 刷新列表并提示「强退成功」；已过期会话的强退 MUST 按幂等成功处理。
- **FR-006**: 在线用户 MUST 支持勾选多条后批量强退；批量强退 MUST 逐条调用单条强退能力；部分失败时 MUST 继续执行其余条目，并以「成功 N 条，失败 M 条」汇总提示，同时展示后端失败原因。
- **FR-007**: 批量强退按钮 MUST 在未勾选任何行时不可用；执行中 MUST 禁止重复触发；确认弹窗取消时 MUST NOT 发起请求。
- **FR-008**: 系统 MUST 按权限码控制菜单与按钮：在线列表与菜单使用 `monitor:online:list`，单条强退使用 `monitor:online:forceLogout`，批量强退 MUST 同时具备 `monitor:online:batchLogout` 与 `monitor:online:forceLogout`，缓存页使用 `monitor:cache:list`，Admin 页使用 `monitor:admin:list`，任务调度页使用 `monitor:snailjob:list`；无权限的按钮 MUST NOT 渲染。
- **FR-009**: 缓存监控页 MUST 展示 Redis 版本、运行模式、端口、客户端数、运行时间（天）、使用内存、使用 CPU、内存配置、AOF 是否开启、RDB 是否成功、Key 数量、网络入口/出口 12 项基本信息；运行模式、AOF 状态与 CPU 数值 MUST 按既定用户可读规则转换。
- **FR-010**: 缓存监控页 MUST 渲染命令统计饼图与内存信息仪表盘；命令统计为空时 MUST 显示「暂无数据」且不渲染空图表；单个字段缺键时 MUST 显示「—」。
- **FR-011**: 缓存监控接口失败时，页面 MUST 展示后端返回的原因原文；基本信息表与图表 MUST NOT 渲染；页面 MUST NOT 吞掉异常。
- **FR-012**: Admin 监控页 MUST 使用部署环境提供的地址内嵌官方控制台；MUST 提供在新窗口打开同一地址的入口；地址为空时 MUST 显示「未配置监控地址」且不渲染内嵌区域；地址不可达时 MUST 保留内嵌区域与外链。
- **FR-013**: 任务调度中心页 MUST 使用部署环境提供的地址内嵌官方 SnailJob 控制台；MUST 提供在新窗口打开同一地址的入口；地址为空时 MUST 显示「未配置监控地址」且不渲染内嵌区域。
- **FR-014**: 系统 MUST NOT 修改 `platform/`、`frontend/packages/**`、权限码定义或后端接口；MUST NOT 新增前端依赖。
- **FR-015**: 系统 MUST NOT 将会话编号、登录地址、登录地点写入控制台、浏览器存储、埋点或错误上报；请求失败日志 MUST 只包含时间、级别、脱敏路径、原因与错误码。
- **FR-016**: 系统 MUST NOT 提供缓存名称与键名浏览、缓存清理、在线用户导出、自动轮询、定时刷新、SSE 推送；MUST NOT 新增后端批量强退接口。

### Key Entities *(include if feature involves data)*

- **在线会话**：一次登录形成的在线记录，包含会话编号、用户名称、部门名称、客户端标识、设备类型、登录地址、登录地点、浏览器、操作系统与登录时间。
- **缓存运行信息**：Redis 运行属性集合、Key 数量与命令调用统计；属性值均为文本，Key 数量为整数，命令统计由命令名与调用次数组成。
- **外部控制台入口**：Admin 监控与任务调度中心各有一个部署环境提供的地址，用于内嵌与外链打开。
- **监控权限**：控制菜单可见性与操作按钮的权限码集合。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 具备权限的管理员可在 4 个菜单分别进入对应页面，「即将推出」占位页出现次数为 0。
- **SC-002**: 管理员可在 3 分钟内完成「查询在线会话 → 单条强退 → 批量强退」全流程；操作后列表与后端数据一致，页面未捕获异常为 0。
- **SC-003**: 缓存接口返回后 2 秒内页面完成首屏渲染，12 项基本信息与 2 个图表可见；命令统计为空时仍能正常展示空状态。
- **SC-004**: 不具备对应权限的账号看到的强退与批量强退按钮数量为 0；直接访问受限页面时不会发起对应数据请求。
- **SC-005**: 交付变更中 `platform/` 与 `frontend/packages/**` 文件数为 0，新增前端依赖数为 0。
- **SC-006**: 上线后 30 天内与在线用户列表、强退刷新、缓存监控白屏、监控入口 404 相关的工单数为 0（滞后指标，不计入交付完成定义）。

## Assumptions

- 已有后端在线用户、缓存监控接口可用，本特性只消费既有接口，不改后端；在线列表一次返回全部会话，由前端本地分页。
- Admin 监控与任务调度中心是独立部署的官方控制台，允许被内嵌；其自身可用性、内容正确性与加载性能不在本特性范围内。
- 控制台地址由部署环境注入，开发环境与生产环境分别使用既定默认值；源码中不硬编码地址。
- 会话编号、登录地址与登录地点按现有基线在页面表格内完整展示，但不进入日志、浏览器存储、埋点或错误上报。
- 单条强退提示为「强退成功」，批量提示为「成功 N 条，失败 M 条」。
- 目标用户为桌面端现代浏览器中的中文界面管理员与运维人员；不做移动端与响应式专项适配。
- 缓存键浏览、缓存清理、在线导出、自动刷新与后端批量强退接口不在本期范围；如后续需要，另行升版规格。

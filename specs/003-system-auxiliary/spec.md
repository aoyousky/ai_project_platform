# Feature Specification: 系统管理辅助模块（字典 / 参数 / 公告 / 日志 / 文件）

**Feature Branch**: `003-system-auxiliary`

**Created**: 2026-11-07

**Status**: Draft

**Input**: User description: "系统管理辅助模块：字典管理（类型+字典数据隐藏页）、参数设置、通知公告、操作日志、登录日志、文件管理（OSS 列表+OSS 配置隐藏页）前端交付。范围：8 个视图，行为对齐现有 plus-ui 与后端既有接口，不修改 platform/，不新增依赖。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 字典维护 (Priority: P1)

系统管理员在同一页面维护字典类型及其字典数据：左侧列出字典类型，选中某个类型后右侧展示该类型的字典数据，可在两侧分别新增、修改、删除、导出，并可刷新字典缓存使变更立即被全站使用。后端菜单中的隐藏字典数据页也可通过带类型编号的地址直接进入。

**Why this priority**: 字典是状态、类型、性别等全站枚举的唯一来源；字典维护不可用会导致其他业务页面展示错误标签，属于最高频的系统管理基础能力。

**Independent Test**: 仅实现本故事即可独立验收：打开字典管理页，新增一个字典类型与两条字典数据，修改其中一条、删除另一条，刷新页面后结果与后端一致；删除已分配数据的字典类型被拒绝并展示原因。

**Acceptance Scenarios**:

1. **Given** 字典类型 `T` 已存在且包含字典数据 `D1`、`D2`，**When** 打开字典管理页，**Then** 左侧列表出现 `T`，右侧展示 `D1`、`D2` 的标签、键值、排序、备注与创建时间。
2. **Given** 已选中字典类型 `T`，**When** 新增字典数据 `D3`，**Then** 页面提示成功，右侧列表刷新后包含 `D3`，且全站使用 `T` 的页面能读取到 `D3`。
3. **Given** 字典类型 `T` 已被字典数据引用，**When** 删除 `T`，**Then** 页面展示后端返回的非空原因，`T` 仍保留在左侧列表，右侧数据不变。
4. **Given** 直接访问隐藏字典数据页并携带有效类型编号，**When** 页面加载，**Then** 展示该类型的数据列表与维护入口；编号无效时展示空状态或错误提示，页面不崩溃。

---

### User Story 2 - 参数维护 (Priority: P1)

系统管理员按参数名称、参数键名、系统内置标记与创建时间筛选参数，新增、修改、删除参数，刷新参数缓存，并导出当前筛选结果。系统内置参数只能查看与修改，不能被删除。

**Why this priority**: 参数控制 OSS 预览开关、验证码开关等运行时行为；参数误删或缓存未刷新会造成线上功能异常，属于系统管理核心能力。

**Independent Test**: 新增一个非内置参数，修改参数值，刷新缓存，删除该参数；再尝试删除一个系统内置参数，确认被拒绝并展示可理解原因。

**Acceptance Scenarios**:

1. **Given** 参数列表非空，**When** 按参数名称与系统内置标记筛选，**Then** 列表只展示匹配记录，总数同步更新。
2. **Given** 参数键名不存在，**When** 新增参数并保存，**Then** 提示成功，列表出现该参数；修改参数值后列表同步更新；删除后列表不再出现。
3. **Given** 某参数为系统内置，**When** 删除该参数，**Then** 操作被拒绝并展示非空原因，列表仍包含该参数。
4. **Given** 任意筛选条件，**When** 点击刷新缓存，**Then** 提示成功，页面不报错，后续读取该参数的页面拿到最新值。

---

### User Story 3 - 通知公告 (Priority: P1)

系统管理员按公告标题、操作人员、公告类型筛选通知公告，新增、修改、删除公告，并使用富文本编辑公告内容；公告类型区分“通知”与“公告”，状态区分“正常”与“关闭”。历史公告内容在详情/编辑回显时保持原有排版。

**Why this priority**: 通知公告是平台对内部用户发布信息的唯一渠道；内容无法编辑或显示错乱会直接影响信息传达。

**Independent Test**: 新增一条含居中、大字号等富文本格式的公告，重新打开编辑页确认内容与格式一致；修改标题与状态后列表同步更新；删除后列表不再出现。

**Acceptance Scenarios**:

1. **Given** 公告列表非空，**When** 按标题、操作人员、类型筛选，**Then** 列表只展示匹配记录，类型与状态以中文标签正确显示。
2. **Given** 公告标题与类型已填写，**When** 在富文本编辑器中输入带格式内容并保存，**Then** 提示成功，列表出现该公告；重新打开编辑页时内容与格式保持一致。
3. **Given** 一条历史公告含旧编辑器产生的对齐/字号样式，**When** 查看或编辑该公告，**Then** 对齐与字号仍然生效，文本内容不发生改变。
4. **Given** 公告标题为空或含脚本字符，**When** 提交，**Then** 前端校验拦截或后端拒绝，弹窗保持打开且已填内容不丢失。

---

### User Story 4 - 操作日志审计 (Priority: P2)

系统管理员按操作地址、系统模块、操作人员、操作类型、操作状态与操作时间范围筛选操作日志，查看单条日志的完整详情（登录信息、请求信息、请求参数、返回参数、错误信息、消耗时间），批量删除或清空日志，并导出当前筛选结果。

**Why this priority**: 操作日志用于安全审计与问题追踪；没有它无法定位越权、误操作与接口异常，但日常使用频率低于字典与参数维护。

**Independent Test**: 产生至少一条操作日志后，按模块与操作人员筛选到该条，打开详情核对参数与结果，导出当前筛选结果，再删除该条并确认列表更新。

**Acceptance Scenarios**:

1. **Given** 操作日志列表非空，**When** 组合筛选条件并查询，**Then** 列表只展示匹配记录，总数为匹配条数，分页可用。
2. **Given** 某条日志的请求参数与返回参数为合法 JSON，**When** 打开详情弹窗，**Then** 参数以可读结构展示；参数不是合法 JSON 时按原始文本展示，弹窗不崩溃。
3. **Given** 已勾选一条或多条日志，**When** 执行删除或清空并确认，**Then** 提示成功，列表刷新后对应记录消失。
4. **Given** 当前筛选条件，**When** 执行导出，**Then** 浏览器下载到非空表格文件；后端返回错误体时展示错误原因，不保存损坏文件。

---

### User Story 5 - 登录日志审计 (Priority: P2)

系统管理员按登录地址、用户名称、登录状态与登录时间范围筛选登录日志，查看客户端、设备类型、浏览器、操作系统、提示消息等信息，批量删除或清空日志，对单个被锁定账号执行解锁，并导出当前筛选结果。

**Why this priority**: 登录日志用于排查登录失败、异常 IP 与账号锁定；解锁能力直接影响用户能否恢复登录。

**Independent Test**: 筛选出至少一条登录日志，勾选单条后执行解锁并确认成功；删除该条、清空全部后列表为空；导出当前筛选结果得到非空文件。

**Acceptance Scenarios**:

1. **Given** 登录日志列表非空，**When** 按用户名称、登录状态与时间范围筛选，**Then** 列表只展示匹配记录，状态以中文标签正确显示。
2. **Given** 勾选数量不等于 1，**When** 查看“解锁”入口，**Then** 解锁按钮不可用；仅勾选 1 条时可执行，确认后提示成功。
3. **Given** 已勾选日志，**When** 执行删除或清空并确认，**Then** 提示成功，列表刷新后对应记录消失。
4. **Given** 当前筛选条件，**When** 执行导出，**Then** 浏览器下载到非空表格文件；后端返回错误体时展示错误原因，不保存损坏文件。

---

### User Story 6 - 文件管理 (Priority: P2)

系统管理员按文件名、原名、文件后缀、服务商与创建时间筛选已上传文件，上传普通文件或图片，预览图片，下载文件，批量删除文件，并可跳转到文件配置管理页。列表中的图片预览受全局“OSS 预览列表资源”开关控制。

**Why this priority**: 文件管理承接头像、富文本图片与业务附件的上传、预览与清理；没有它，依赖上传的页面无法闭环。

**Independent Test**: 上传一个图片与一个普通文件，列表出现两条记录；图片在预览开关开启时显示缩略图，关闭后显示地址文本；下载图片成功；删除后列表不再出现。

**Acceptance Scenarios**:

1. **Given** 已具备上传权限，**When** 选择非空文件上传，**Then** 提示成功，列表刷新后出现该文件的原名、后缀、服务商与上传人。
2. **Given** 上传内容为空或上传接口返回失败，**When** 提交上传，**Then** 展示可理解错误，列表不增加记录，页面不崩溃。
3. **Given** 预览开关为开启且文件后缀为图片格式，**When** 查看列表，**Then** 展示图片缩略图；开关关闭或非图片后缀时展示文件地址文本。
4. **Given** 已勾选或多选文件，**When** 执行删除并确认，**Then** 提示成功，列表刷新后记录消失。

---

### User Story 7 - 文件配置管理 (Priority: P2)

系统管理员维护对象存储配置：按配置 key、桶名称、是否默认筛选，新增、修改、删除配置，切换默认配置，并保证同一时间只有一个默认配置。系统内置配置不可删除。

**Why this priority**: 文件配置决定文件上传到哪个存储服务；配置错误会导致上传整体失败，但变更频率低，故排在文件管理之后。

**Independent Test**: 新增一条存储配置并保存，列表出现该配置；将另一条配置设为默认后原默认配置自动变为非默认；删除新增配置成功；尝试删除系统内置配置被拒绝。

**Acceptance Scenarios**:

1. **Given** 配置列表非空，**When** 按配置 key、桶名称与是否默认筛选，**Then** 列表只展示匹配记录，默认状态以开关形式正确显示。
2. **Given** 配置 key 不存在，**When** 新增配置并保存，**Then** 提示成功，列表出现该配置；使用重复配置 key 新增时被拒绝并展示原因。
3. **Given** 某配置当前为默认，**When** 将另一条配置设为默认并确认，**Then** 提示成功，新配置为默认，原默认配置自动取消默认。
4. **Given** 某配置为系统内置，**When** 删除该配置，**Then** 操作被拒绝并展示非空原因，列表仍包含该配置。

---

### Edge Cases

- 列表返回 `rows=[]`：表格显示空状态，总数为 0，不弹错误提示，不无限加载。
- 查询页码超过总页数：返回空列表且总数不变，分页器回到有效页码，页面不出现 `NaN`。
- 后端返回 HTTP 500 或业务失败码：展示后端 `msg` 或统一错误提示，页面不白屏，DOM 不出现堆栈文本。
- 字典类型/参数键名/配置 key 重复：保存被拒绝，表单保持原输入，列表总数不增加。
- 字典类型已被字典数据引用：删除被拒绝，展示后端原因，类型与数据均不变。
- 系统内置参数、系统内置 OSS 配置：删除被拒绝，展示后端原因，记录不变。
- 超出 JavaScript 安全整数范围的编号：按字符串保存、比较与回传，不出现精度丢失。
- 会话过期或令牌失效：只跳转一次登录页，不出现重复跳转或循环；未提交表单内容不进入持久化存储。
- 富文本历史内容含旧编辑器专用类名：对齐与字号仍生效，文本内容与原文一致。
- 公告标题为空或含脚本字符：前端校验拦截或后端拒绝，弹窗保持打开且已填内容不丢失。
- 上传空文件、无权限上传或存储服务不可用：展示可理解错误，列表不增加记录。
- 同一时刻多个配置被设为默认：最终只有一个默认配置；失败时开关回滚到原状态。
- 登录日志解锁时勾选多于一条：解锁入口不可用或拒绝执行，不发送多用户解锁请求。
- 操作日志详情中的参数不是合法 JSON：按原始文本展示，不抛异常。
- 导出接口返回 JSON 错误体：识别响应类型并展示 `msg`，不保存损坏文件。

## Requirements *(mandatory)*

### Functional Requirements

#### 通用能力

- **FR-001**: 系统 MUST 在动态菜单中提供 8 个视图：字典管理、字典数据（隐藏页）、参数设置、通知公告、操作日志、登录日志、文件管理、文件配置管理（隐藏页）；未移植占位页不得出现在这些路径上。
- **FR-002**: 所有列表页 MUST 支持分页（默认每页 10 条）、关键字/枚举/时间范围筛选、重置筛选、加载中、空数据与失败三态。
- **FR-003**: 系统 MUST 按当前账号权限码控制页面入口与操作按钮；无权限的按钮不渲染；直接访问受限页面或执行受限操作时被拒绝且不泄露数据。
- **FR-004**: 所有写操作成功后 MUST 展示成功提示并刷新相关列表；失败时 MUST 展示后端返回的错误原因原文，表单保持打开且已填内容不丢失。
- **FR-005**: 删除、批量删除、清空、解锁、切换默认配置、刷新缓存等敏感操作 MUST 在二次确认后才发起请求。
- **FR-006**: 所有编号 MUST 以字符串兼容方式保存、比较与回传；时间字段 MUST 按后端 `yyyy-MM-dd HH:mm:ss` 字符串直接展示，不做时区换算。
- **FR-007**: 页面 MUST 不吞掉异常；接口失败时展示可理解错误，控制台不得出现未捕获异常或堆栈文本。

#### 字典管理

- **FR-008**: 字典管理页 MUST 采用双栏联动：左侧为字典类型列表，右侧为当前选中类型的字典数据列表；未选中类型时右侧显示空状态与提示。
- **FR-009**: 字典类型列表 MUST 支持按字典名称、字典类型、创建时间范围筛选，并展示字典名称、字典类型、备注、创建时间。
- **FR-010**: 字典类型 MUST 支持新增、单条修改、批量删除、导出与刷新缓存；点击类型行或类型名称 MUST 加载该类型的字典数据。
- **FR-011**: 字典类型表单 MUST 校验字典名称必填且不超过 100 字符、字典类型必填且不超过 100 字符、字典类型以字母开头且仅含小写字母/数字/下划线；字典类型 MUST 唯一。
- **FR-012**: 字典数据列表 MUST 支持按字典标签筛选，展示字典标签、字典键值、字典排序、备注、创建时间；MUST 支持新增、单条修改、批量删除与导出。
- **FR-013**: 字典数据表单 MUST 校验字典标签与字典键值必填且不超过 100 字符，字典类型只读继承当前类型；排序为非负整数；备注、样式属性、回显样式可选。
- **FR-014**: 删除已被字典数据引用的字典类型 MUST 被拒绝并展示后端原因；刷新字典缓存 MUST 清理前端会话字典缓存，使后续页面重新获取最新字典。
- **FR-015**: 隐藏字典数据页 MUST 能按地址中的类型编号加载该类型的字典数据，提供返回字典管理页的入口；编号不存在时展示空状态或错误提示且不崩溃。

#### 参数设置

- **FR-016**: 参数列表 MUST 支持按参数名称、参数键名、系统内置标记、创建时间范围筛选，并展示参数名称、参数键名、参数键值、系统内置、备注、创建时间。
- **FR-017**: 参数 MUST 支持新增、单条修改、批量删除、导出与刷新缓存。
- **FR-018**: 参数表单 MUST 校验参数名称、参数键名、参数键值必填，长度分别不超过 100、100、500 字符；系统内置标记 MUST 为“是/否”之一；前端 MUST NOT 增加后端未实现的唯一性校验（参数键名按后端既有规则允许重复）。
- **FR-019**: 系统内置参数 MUST 不可删除，删除被拒绝时展示后端原因；刷新参数缓存成功后 MUST 提示成功。

#### 通知公告

- **FR-020**: 公告列表 MUST 支持按公告标题、操作人员、公告类型筛选，并展示公告标题、公告类型、状态、创建者、创建时间。
- **FR-021**: 公告 MUST 支持新增、单条修改、批量删除；公告类型 MUST 支持“通知/公告”，状态 MUST 支持“正常/关闭”。
- **FR-022**: 公告表单 MUST 校验公告标题必填且不超过 50 字符、不得包含脚本字符，公告类型必填；公告内容 MUST 使用富文本编辑器编辑与回显。
- **FR-023**: 历史公告内容含旧编辑器专用类名时 MUST 保持对齐/字号效果，文本内容不得被改写；富文本渲染 MUST 防止脚本注入。

#### 操作日志

- **FR-024**: 操作日志列表 MUST 支持按操作地址、系统模块、操作人员、操作类型、操作状态、操作时间范围筛选，并展示日志编号、系统模块、操作类型、请求方式、操作人员、部门、操作地址、操作状态、操作时间、消耗时间。
- **FR-025**: 操作日志列表 MUST 默认按操作时间倒序，并支持按操作人员、操作时间、消耗时间排序（后端支持时）。
- **FR-026**: 操作日志 MUST 支持查看详情、批量删除、清空与导出；详情 MUST 展示操作状态、登录信息、请求信息、操作模块、操作方法、请求参数、返回参数、消耗时间、操作时间与异常信息。
- **FR-027**: 请求参数与返回参数为合法 JSON 时 MUST 以可读结构展示；非合法 JSON 时 MUST 按原始文本展示且不崩溃。

#### 登录日志

- **FR-028**: 登录日志列表 MUST 支持按登录地址、用户名称、登录状态、登录时间范围筛选，并展示访问编号、用户名称、客户端、设备类型、登录地址、登录地点、操作系统、浏览器、登录状态、描述、访问时间。
- **FR-029**: 登录日志列表 MUST 默认按访问时间倒序，并支持按用户名称、访问时间排序（后端支持时）。
- **FR-030**: 登录日志 MUST 支持批量删除、清空、导出；对单个被锁定账号 MUST 支持解锁，解锁入口仅在恰好勾选 1 条时可用。
- **FR-031**: 解锁 MUST 使用所选记录的用户名称发起请求，并在二次确认后执行；成功与失败均 MUST 给出明确提示。

#### 文件管理

- **FR-032**: 文件列表 MUST 支持按文件名、原名、文件后缀、服务商、创建时间范围筛选，并展示文件名、原名、文件后缀、文件展示/预览、创建时间、上传人、服务商。
- **FR-033**: 文件管理 MUST 支持上传普通文件、上传图片、批量删除与下载；上传成功后 MUST 刷新列表并展示成功提示。
- **FR-034**: 文件列表 MUST 在全局“OSS 预览列表资源”开关开启且后缀为 `png/jpg/jpeg` 时展示图片缩略图；否则展示文件地址文本。
- **FR-035**: 预览开关 MUST 在二次确认后写入参数 `sys.oss.previewListResource`（`true/false`），写入成功后刷新列表；按钮权限按实际调用接口所需权限控制。
- **FR-036**: 文件管理页 MUST 提供“配置管理”入口，按文件配置列表权限控制可见性，并跳转到隐藏的文件配置管理页。
- **FR-037**: 下载 MUST 使用文件编号获取文件内容；后端返回错误时 MUST 展示错误原因，不保存损坏文件。

#### 文件配置管理

- **FR-038**: 文件配置列表 MUST 支持按配置 key、桶名称、是否默认筛选，并展示配置 key、访问站点、自定义域名、桶名称、前缀、域、桶权限类型、是否默认、备注。
- **FR-039**: 文件配置 MUST 支持新增、单条修改、批量删除；默认状态 MUST 以开关展示并支持切换。
- **FR-040**: 文件配置表单 MUST 校验配置 key、accessKey、secretKey、桶名称、访问站点、桶权限类型必填，长度 2–100 字符；配置 key MUST 唯一；`isHttps` MUST 为“是/否”，桶权限类型 MUST 为 `private/public/custom` 之一；secretKey 输入 MUST 默认遮蔽。
- **FR-041**: 切换默认配置 MUST 在二次确认后执行；成功后同一时间只有一个默认配置，原默认配置自动取消；失败时开关 MUST 回滚为原状态。
- **FR-042**: 系统内置文件配置 MUST 不可删除，删除被拒绝时展示后端原因。

#### 兼容与边界

- **FR-043**: 所有页面 MUST 使用既有后端接口、错误结构与权限码，不得修改 `platform/` 任何接口、字段、错误码、权限码或 SQL。
- **FR-044**: 所有页面 MUST 使用既有前端依赖与组件；不得新增第三方依赖、全局 renderer 或修改 `packages/**` 上游实现。
- **FR-045**: 后端返回的 ID 为数字或字符串时，前端 MUST 统一按字符串比较与回传；不得因精度丢失导致编辑/删除失败。

### Key Entities

- **字典类型 (DictType)**: 字典的唯一类型标识与名称，包含字典名称、字典类型、备注、创建时间；可被多条字典数据引用。
- **字典数据 (DictData)**: 某个字典类型下的可选项，包含标签、键值、排序、样式属性、回显样式、备注、创建时间；同一类型下键值唯一。
- **参数 (Config)**: 运行时配置项，包含参数名称、参数键名、参数键值、系统内置标记、备注、创建时间；系统内置参数受删除保护。
- **通知公告 (Notice)**: 面向内部用户的信息，包含标题、类型（通知/公告）、状态（正常/关闭）、富文本内容、创建者、创建时间。
- **操作日志 (OperLog)**: 后台操作审计记录，包含模块、业务类型、请求方式、操作人员、部门、地址、请求参数、返回参数、状态、错误信息、操作时间、消耗时间。
- **登录日志 (Logininfor)**: 登录审计记录，包含用户名称、客户端、设备类型、登录地址、登录地点、浏览器、操作系统、登录状态、提示消息、访问时间。
- **文件 (Oss)**: 已上传对象存储文件，包含文件名、原名、后缀、访问地址、服务商、上传人、创建时间。
- **文件配置 (OssConfig)**: 对象存储服务配置，包含配置 key、accessKey、secretKey、桶名称、前缀、访问站点、自定义域名、是否 HTTPS、域、桶权限类型、是否默认、备注；同一时间仅一个默认配置，系统内置配置受删除保护。

## Assumptions

- **行为基线**: 以 plus-ui 删除前最后一个提交（`0534d3d^`）中的页面与交互为基线；不新增 plus-ui 之外的业务功能。
- **后端契约**: 后端接口、字段、分页结构、错误结构与权限码保持不变；前端只消费既有返回。已核对的后端事实：字典类型由数据库唯一约束保证同租户内不重复（重复时返回 `code=409`、`msg='数据库中已存在该记录，请联系管理员确认'`）；参数键名、字典数据键值在后端均无唯一约束，前端不自创校验；文件配置 key 由后端服务校验唯一。
- **筛选字段**: 公告列表只按标题、操作人员、公告类型筛选，后端不支持状态与时间范围筛选；日志列表的日期范围参数放在 `params[beginTime]` / `params[endTime]`，文件列表放在 `params[beginCreateTime]` / `params[endCreateTime]`。
- **权限码**: 字典使用 `system:dict:*`，参数使用 `system:config:*`，公告使用 `system:notice:*`，操作日志使用 `monitor:operlog:*`，登录日志使用 `monitor:logininfor:*`，文件使用 `system:oss:*`，文件配置使用 `system:ossConfig:*`。
- **预览开关权限**: plus-ui 用 `system:oss:edit` 渲染预览开关，但基线权限表中不存在该权限码，且实际写入参数接口校验 `system:config:edit`。本规格默认按 `system:config:edit` 控制该开关；若业务坚持 plus-ui 的权限码，需在 Spec Packet 签字前修改后端权限表（超出本需求）。
- **隐藏字典数据页**: plus-ui 的字典页为双栏单页；隐藏菜单 `dict-data/index/:dictId` 指向的独立组件在原基线中不存在。本规格按用户选择实现独立字典数据页，复用同一数据维护能力。
- **富文本**: 使用产品现有富文本编辑能力，不新增编辑器依赖；历史内容中的旧编辑器样式由兼容样式承接（SPEC-001 E-19），不保证新编辑器产出 HTML 与 plus-ui 逐字节一致。
- **文件预览**: 仅 `png/jpg/jpeg` 后缀展示缩略图；其他类型展示地址文本。
- **默认配置**: 文件配置的 `status` 语义为 `0=默认（是）`、`1=非默认（否）`；切换默认后同一时间仅一条为默认。
- **运行环境**: 桌面端现代浏览器、中文界面；不做移动端/响应式专项适配。
- **日期与编号**: 时间按后端字符串直出；编号统一兼容数字与字符串。
- **分页**: 默认每页 10 条；页码越界时回到有效页码。
- **不包含**: 客户端管理、租户、租户套餐、监控（在线用户/缓存）、代码生成、演示页面、工作流与任务、个人中心。

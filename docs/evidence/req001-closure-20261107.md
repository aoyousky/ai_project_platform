### 1.2 R10 图标映射要点

## 5. §5 性能口径实测

方法（`frontend/tests/perf/req001-probe.mjs`）：生产构建 + 本地 Docker 栈；登录往返 = `POST /auth/login` 请求发出到响应返回，**3 次独立登录取中位数**（每次重新取验证码）；首页可交互 = `goto('/index', waitUntil:'load')` 后首个侧栏导航项可点击（trial click）；路由切换 = 菜单项 **DOM click 派发**到 URL 变化（不含菜单展开/收起动画的 actionability 等待，也不含接口耗时）；warm 取 **5 次中位数**，首次（含目标页懒加载 chunk）单独记为 cold。

采样口径说明：本机存在周期性调度抖动，单次样本可 >1s（同一次运行中 login 样本 1746/265/360、route 样本 122/89/92/1283/305）。单样本测量会把抖动误判为性能不达标，因此登录与路由切换均取中位数，并完整保留原始样本供复核；阈值未做任何调整。

| 指标 | SPEC-001 §5 阈值 | 本次实测（2026-11-07T12:35:35+08:00） |
|---|---|---|
| 登录往返（中位数） | ≤ 2000ms | **360ms**（样本 1746 / 265 / 360） |
| 首页可交互 | ≤ 3000ms | **2082ms** |
| 路由切换（warm 中位数） | ≤ 500ms | **122ms**（样本 122 / 89 / 92 / 1283 / 305） |
| 路由切换（cold，含懒加载） | 参考项 | 295ms |
| 生产构建产物 | ≤ 8MB | **5,461,715 字节（5.21 MiB，254 文件）** |
| 构建产物压缩包 | — | 1,685,039 字节（1.61 MiB） |

注：首页可交互本次 2082ms，接近阈值上限（前次同构建 1048ms）；测量窗口包含浏览器 load 与首屏可点击判定，受本机抖动影响，仍在 3s 内。

## 7. 已知边界与说明

- E-09 的替换发生在路由生成前、以 `pageMap` 的实际文件清单为准；后端新增菜单指向未移植组件时自动落到占位页，无需维护手工白名单。
- `ComingSoon` 走 `layoutMap` 而非 `pageMap`，因为其组件值来自后端菜单的 `component` 字段，由 `generateRoutesByBackend` 在 layoutMap 中查找；这与 Vben 上游对 `Layout/ParentView` 的处理一致。
- 图标映射为静态表 + fallback；后端换用未登记图标名时不会中断渲染，只产生一次 console warn。
- 性能数据仅代表本机（Windows 10、本地 Docker 栈、Edge headless）测量，用作阈值合规证据，不作为容量结论。
